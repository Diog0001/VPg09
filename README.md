# Вязь

> Классические таск-трекеры работают с деревом.  
> **Вязь** работает с графом отношений задач — и не выкидывает доску.

В интерфейсе — «Вязь». В коде, пакетах и URL — `vyaz`.



---

## Зафиксированный промпт

Полный текст: [PROMPT.md](./PROMPT.md)

Сжато:

1. Вход — доска, как в обычном трекере.
2. Открыл таск — **превью**. В конструктор mindmap вход отдельной кнопкой.
3. Все ветвления — тоже задачи. У задачи есть тип: дефолтные `task`, `note`, `sketch`, `design` и свои.
4. Связь может быть любой; важен тип и слой связи — это не то же самое, что тип карточки.
5. Три пути: **основной** (контекст → контекст), **второстепенный** (контекст → косвенное), **ключевой** (не может существовать автономно). На каждом пути стоят задачи.
6. Пространство продукта настраивается: агенты, ИИ-провайдеры, форматы досок и карточек, типы задач.
7. Глобальный конфиг + конфиг продукта.
8. К пространству подключается история GitHub и документы — топливо для рекомендаций и описаний.
9. Иерархия не запрещена, она частный случай графа.

## Документы

| Файл | Зачем открывать |
|---|---|
| [PROMPT.md](./PROMPT.md) | Исходная постановка, инварианты. Нельзя «улучшить» так, чтобы они пропали. |

Как пользоваться в Cursor: в начале фазы прикладывать `PROMPT.md` + текущую фазу из `plan.md` + соответствующие разделы архитектуры и ТЗ. Не просить сразу весь продукт.

## Чем это не является

- Не Notion с графом в углу.
- Не Miro с приклеенными стикерами-задачами.
- Не Jira с полем «epic link».
- Не чат с LLM, который генерирует TODO-список.

Ребро — такая же сущность, как задача. ИИ предлагает, человек подтверждает. Ключевые связи нельзя наплодить молча.

## Стек

Зафиксирован. FastAPI — основной бэкенд, не эксперимент.

| Слой | Выбор |
|---|---|
| API | Python 3.12, FastAPI, SQLAlchemy 2, Alembic |
| БД | PostgreSQL 16 |
| Граф / ИИ | NetworkX в API, OpenAI-compatible SDK, SSE |
| Web | Vite, React, TypeScript, свои примитивы (коралл `#fb605e`, Inter, Crimson Text) |
| Холст | **XYFlow** (`@xyflow/react`) + ELK для автоукладки; ноды и рёбра свои, в стиле кита |
| Клиент API | OpenAPI → TypeScript |
| Dev | Docker Compose (Postgres + API) |

Не используем: shadcn, Tailwind-как-дизайн-система, Next.js-монолит, Kafka, Kubernetes.

Тяжёлая инфраструктура из черновика DeepSeek отложена. См. ADR-4 в архитектуре.

## Запуск

```bash
cp .env.example .env
docker compose up -d
# Postgres: 127.0.0.1:55432 (чтобы не спорить с локальным PostgreSQL)
cd apps/api
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

В другом терминале:

```bash
cd apps/web
npm install
npm run dev
```

- UI: `http://localhost:5173` (демо `demo@vyaz.local` / `demo`)
- Swagger: `http://localhost:8000/docs`

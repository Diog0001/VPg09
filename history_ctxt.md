# История контекста Вязь

Сюда агент **сам** выгружает сжатую историю переписки. Не ждать просьбы пользователя.

## Правило выгрузки

Дамп писать, если верно **любое** условие (ИЛИ), не вместо друг друга:

- автономно: `3 сессии == сохранить контекст сюда`;
- явно: пользователь попросил дамп / снимок / сохранить контекст.

`last_dump_reason` — только метка последнего дампа (`autonomous` или `явный запрос`). Она не переключает режим и не отменяет автономную фиксацию. После ручного дампа счётчик обнуляется, цикл 3 сессий продолжается.

| Поле | Значение |
|---|---|
| `period` | 3 |
| `dump_triggers` | autonomous **или** явный запрос |
| `sessions_since_dump` | 2 |
| `last_dump_at` | 2026-10-10 |
| `last_dump_reason` | autonomous |
| `next_dump_after` | ещё 2 сессии |
| `restored_at` | 2026-10-09 — файл случайно удалили, восстановлен из дампа 1 |

Как считать сессию: один чат Cursor с пользователем по этому репозиторию. Новая сессия = новый чат или явный обрыв контекста.

Что писать в дамп: решения, поправки к модели, стек, что сделано в файлах, открытые вопросы. Не стенограмму и не содержимое промпта целиком (он в `PROMPT.md`).

## Дамп 4 — 2026-10-10

Три сессии после дампа 3 (явный запрос). Счётчик в шапке ошибочно оставался 0 — пользователь поправил. Дамп autonomous.

### Решения

- Смена вида ребра свободная: primary ↔ secondary ↔ key в любую сторону. Уникальный ключ `(source, target, kind, type)` больше не блокирует PATCH: соседние рёбра пары удаляются. В UI вместо Carbon Dropdown — три кнопки `KindSwitch` (панель инструментов и превью).
- Удаление задачи — soft delete на доске и в mindmap. Если есть key-связи — 409 и повтор с `force=true`.
- Удаление ребра не снимает задачу с холста. Узел получает статус конструктора **«Без связи»** (не колонка доски).
- При уходе с mindmap («На доску», логотип «Вязь», вход в другой конструктор) — диалог: оставить оторванные задачи в этом конструкторе или убрать с холста. Задачи на доске остаются.
- С доски можно положить существующие задачи на холст без ребра (`С доски`).

### Поправки к домену / стеку / UX

- `ViewState.pinned_ids` — какие задачи держать на конкретном фокус-холсте без ребра. Alembic `002`.
- `LeaveGuardProvider` перехватывает уход из конструктора.
- DELETE `/tasks/{id}?force=`, DELETE `/edges/{id}` с фронта. `ApiError` пробрасывает 409.
